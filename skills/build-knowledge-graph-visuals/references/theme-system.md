## 1. 选择严格布局档案

课程章节默认对齐 `course-reference-style.md` 中用户认可的径向成品。其中心圆、渐变模块、浅色卫星节点与总结框是首选视觉语言。下列档案描述现有脚本能力；容量不足时按该参考扩展径向模板，不自动改成双列叙事图。

### `story-loop`：高密度叙事闭环

- 固定画布：`1080x3000`，按 2 倍渲染为 `2160x6000`。
- 目标：同时表达时代前提、核心机制、产出、反例、检验与约束。
- 节点：中心 1 个，加 10–14 个固定语义槽位。
- 关系：12–24 条；只有反馈、回路或成立条件可使用左右 rail。
- 配色：按 `机制 / 问题 / 约束 / 验证 / 行动 / 边界` 六类语义着色，不按所在分组统一染色。

### `mobile-radial`：手机直读

- 固定画布：`1080x2600`。
- 目标：以约 390 CSS px 宽度显示时，无需缩放即可阅读关键标签。
- 最小关键文字：SVG 画布上不小于 34-38 px。
- 节点：最多 13 个；3-4 个语义组，每组最多 2 个卫星节点。
- 关系标签：只保留强关系，弱关联尽量不写文字。

### `poster-radial`：关系海报

- 固定画布：`1800x2600`，按 2 倍渲染为 `3600x5200`。
- 目标：课程页面展示整体结构，允许点击或缩放查看细节。
- 最小文字：18-24 px；但必须明确说明需要缩放。
- 节点：最多 25 个；3–6 个语义组，每组最多 3 个卫星节点。5–6 组或任一组含 3 个外围节点时自动采用 1800×2800 扩展布局，2 倍导出为 3600×5600。

`knowledge-graph-method-*` 示例属于 `poster-radial`；`fde-story-loop-*` 示例属于 `story-loop`。先判断参考图的空间语法，不要只看“都有中心节点”。

不要因为文件像素很大就称其为“手机可读”。可读性由显示后的实际字号决定，不由导出分辨率决定。

## 2. 共享几何原则

黑底和白底必须使用同一个 SVG 几何母版：

- 节点坐标一致。
- 节点尺寸一致。
- 文案一致。
- 关系路径一致。
- 仅替换颜色、透明度、阴影和边框变量。

推荐把主题颜色集中在 `<style>` 或 CSS 变量中，禁止复制后分别修改内容。

## 3. 版式结构

两个径向档案共享以下结构：

1. 顶部：标题、副标题、读图说明。
2. 图例：节点类型、强关系、弱关联。
3. 图谱视觉中心：唯一中心对象。
4. 第一圈：poster 为 3–6 个语义组，密集模式使用专用环绕槽位；mobile 为 3–4 组。
5. 外圈：一级节点的解释、问题、约束或指标。
6. 底部：一句核心判断或复习闭环。

安全区：

- 左右边距至少为画布宽度的 4%。
- 顶部标题区与图例之间至少留一个正文行高。
- 节点文字与边框的水平安全边距至少 36 px，垂直至少 24 px。
- 关系标签不得覆盖箭头、节点或其他标签。

节点圆角、尺寸、环半径和中心坐标由渲染器拥有。调用方不得覆盖。

## 4. 字体与字号

字体栈：

```css
-apple-system, BlinkMacSystemFont, "PingFang SC", "Noto Sans CJK SC", "Microsoft YaHei", sans-serif
```

Poster 画布 `1800x2600` 的参考层级：

| 层级 | 字号 | 字重 |
|---|---:|---:|
| 主标题 | 70 | 900 |
| 副标题 | 31 | 500 |
| 读图说明 | 24 | 400 |
| 中心标题 | 46 | 900 |
| 一级节点标题 | 30 | 800-900 |
| 一级节点副文 | 21 | 400 |
| 外圈标题 | 23 | 700-800 |
| 外圈副文 | 18 | 400 |
| 关系标签 | 19 | 700 |

Mobile 画布 `1080px` 宽时，最小关键标签不低于 34 px；正文副文建议 30-34 px。若装不下，先删节点或缩短文字，不要无限缩小字号。

## 5. 黑底主题

参考变量：

```css
--bg-start: #263246;
--bg-mid: #151d2b;
--bg-end: #090d16;
--title: #f8fafc;
--body: #cbd5e1;
--muted: #94a3b8;
--panel: #0f172a;
--panel-stroke: #334155;
--strong-edge: #67e8f9;
--accent-edge: #fbbf24;
--weak-edge: #94a3b8;
```

黑底可以使用轻微径向渐变，但不能让背景成为视觉主体。白色文字与浅色节点之间必须保持边界，不要把节点副文设成过浅灰。

## 6. 白底主题

参考变量：

```css
--bg-start: #ffffff;
--bg-mid: #ffffff;
--bg-end: #ffffff;
--title: #0f172a;
--body: #334155;
--muted: #64748b;
--panel: #ffffff;
--panel-stroke: #cbd5e1;
--strong-edge: #0891b2;
--accent-edge: #d97706;
--weak-edge: #64748b;
```

白底版不能简单反色。需要分别调整：

- 标题和说明文字改为深色。
- 弱关联提高到能看见但不抢主线的灰度。
- 关系标签改为白底深字并增加浅边框。
- 阴影从黑色重阴影改为低透明度灰蓝阴影。
- 圆环改为浅灰，避免消失。

## 7. 连线与标签

- 强关系：2.8-3.6 px 实线，带箭头，透明度 0.55-0.75。
- 强关系必须有动词标签。
- 弱关联：2-2.5 px 虚线，透明度 0.3-0.5。
- 弱关联只表达辅助联系，不能承担核心推理。
- 连线尽量在节点下方绘制，再绘制节点和文字，避免穿字。
- 标签背景使用小圆角矩形，四周至少 12-16 px 内边距。
- 禁止沿画布边缘绕行的超长关系线。出现这种需求说明内容应拆图，或跨组关系过多。
- poster 最多 5 条额外跨组关系；mobile 最多 3 条。
- 一级节点与中心之间的强关系由每个 group 的 `relation` 字段生成。

## 8. 导出规范

保留：

- SVG 母版：可编辑、可无限缩放。
- PNG：课程页面首选，文字边缘和渐变更稳定。
- JPG：仅在平台限制或文件体积要求下提供，质量不低于 94。

Poster 默认 2 倍渲染：`1800x2600 -> 3600x5200`。

Mobile 默认 2 倍渲染：`1080x2600 -> 2160x5200`。

Story loop 默认 2 倍渲染：`1080x3000 -> 2160x6000`。

v2 示例：

- `assets/examples/knowledge-graph-method-spec.json`
- `assets/examples/knowledge-graph-method-dark.svg`
- `assets/examples/knowledge-graph-method-dark.png`
- `assets/examples/knowledge-graph-method-light.svg`
- `assets/examples/knowledge-graph-method-light.png`

上述方法论示例属于 `poster-radial` 技术回归 fixture。首选成品效果以 `assets/examples/course-reference/` 为准。mobile 使用相同的中心辐射语法，但节点更少、字号更大。

`story-loop` 的可执行示例为 `assets/examples/fde-story-loop-spec.json`。其六类配色、双列节奏、中心胶囊与关系 rail 是模板的一部分。
