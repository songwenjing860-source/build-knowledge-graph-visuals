## 1. 选择密度档

### Mobile：手机直读

- 推荐画布：`1080x2200` 到 `1080x3000`。
- 目标：以约 390 CSS px 宽度显示时，无需缩放即可阅读关键标签。
- 最小关键文字：SVG 画布上不小于 34-38 px。
- 节点：10-16 个。
- 关系标签：只保留强关系，弱关联尽量不写文字。

### Poster：深度海报

- 推荐画布：`1800x2600`，按 2 倍渲染为 `3600x5200`。
- 目标：课程页面展示整体结构，允许点击或缩放查看细节。
- 最小文字：18-24 px；但必须明确说明需要缩放。
- 节点：18-28 个。

不要因为文件像素很大就称其为“手机可读”。可读性由显示后的实际字号决定，不由导出分辨率决定。

## 2. 共享几何原则

黑底和白底必须使用同一个 SVG 几何母版：

- 节点坐标一致。
- 节点尺寸一致。
- 文案一致。
- 关系路径一致。
- 仅替换颜色、透明度、阴影和边框变量。

推荐把主题颜色集中在 `<style>` 或 CSS 变量中，禁止复制后分别修改内容。

## 3. 版式结构

默认竖版网状结构：

1. 顶部：标题、副标题、读图说明。
2. 图例：节点类型、强关系、弱关联。
3. 上部：输入理解或前置能力。
4. 中部：中心能力和第一圈关键模块。
5. 下部：问题优化、机制和评估指标。
6. 底部：一句核心判断或复习闭环。

安全区：

- 左右边距至少为画布宽度的 4%。
- 顶部标题区与图例之间至少留一个正文行高。
- 节点文字与边框的水平安全边距至少 36 px，垂直至少 24 px。
- 关系标签不得覆盖箭头、节点或其他标签。

节点圆角保持克制：外圈 24-30 px，一级节点 32-40 px。中心节点可用圆形或柔和椭圆，但不能靠发光掩盖文字。

## 4. 字体与字号

字体栈：

```css
-apple-system, BlinkMacSystemFont, "PingFang SC", "Noto Sans CJK SC", "Microsoft YaHei", sans-serif
```

Poster 画布 `1800x2600` 的参考层级：

| 层级 | 字号 | 字重 |
|---|---:|---:|
| 主标题 | 70 | 900 |
| 副标题 | 31 | 500 |
| 读图说明 | 24 | 400 |
| 中心标题 | 46 | 900 |
| 一级节点标题 | 30 | 800-900 |
| 一级节点副文 | 21 | 400 |
| 外圈标题 | 23 | 700-800 |
| 外圈副文 | 18 | 400 |
| 关系标签 | 19 | 700 |

Mobile 画布 `1080px` 宽时，最小关键标签不低于 34 px；正文副文建议 30-34 px。若装不下，先删节点或缩短文字，不要无限缩小字号。

## 5. 黑底主题

参考变量：

```css
--bg-start: #263246;
--bg-mid: #151d2b;
--bg-end: #090d16;
--title: #f8fafc;
--body: #cbd5e1;
--muted: #94a3b8;
--panel: #0f172a;
--panel-stroke: #334155;
--strong-edge: #67e8f9;
--accent-edge: #fbbf24;
--weak-edge: #94a3b8;
```

黑底可以使用轻微径向渐变，但不能让背景成为视觉主体。白色文字与浅色节点之间必须保持边界，不要把节点副文设成过浅灰。

## 6. 白底主题

参考变量：

```css
--bg-start: #ffffff;
--bg-mid: #ffffff;
--bg-end: #ffffff;
--title: #0f172a;
--body: #334155;
--muted: #64748b;
--panel: #ffffff;
--panel-stroke: #cbd5e1;
--strong-edge: #0891b2;
--accent-edge: #d97706;
--weak-edge: #64748b;
```

白底版不能简单反色。需要分别调整：

- 标题和说明文字改为深色。
- 弱关联提高到能看见但不抢主线的灰度。
- 关系标签改为白底深字并增加浅边框。
- 阴影从黑色重阴影改为低透明度灰蓝阴影。
- 圆环改为浅灰，避免消失。

## 7. 连线与标签

- 强关系：2.8-3.6 px 实线，带箭头，透明度 0.55-0.75。
- 强关系必须有动词标签。
- 弱关联：2-2.5 px 虚线，透明度 0.3-0.5。
- 弱关联只表达辅助联系，不能承担核心推理。
- 连线尽量在节点下方绘制，再绘制节点和文字，避免穿字。
- 标签背景使用小圆角矩形，四周至少 12-16 px 内边距。

## 8. 导出规范

保留：

- SVG 母版：可编辑、可无限缩放。
- PNG：课程页面首选，文字边缘和渐变更稳定。
- JPG：仅在平台限制或文件体积要求下提供，质量不低于 94。

Poster 默认 2 倍渲染：`1800x2600 -> 3600x5200`。

Mobile 默认 2 倍渲染：`1080x2400 -> 2160x4800`。

示例：

- `assets/examples/knowledge-graph-method-dark.svg`
- `assets/examples/knowledge-graph-method-dark.png`
- `assets/examples/knowledge-graph-method-light.svg`
- `assets/examples/knowledge-graph-method-light.png`

示例属于 Poster 密度，只校准视觉语言，不代表手机直读的字号标准。
