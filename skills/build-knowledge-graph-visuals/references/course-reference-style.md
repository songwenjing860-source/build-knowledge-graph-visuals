# 用户认可的课程图谱样式

这些成品是默认视觉标杆。生成前实际打开所选图片，结合 SVG 查看字体、坐标、配色和关系曲线。原样保留参考文件；旧方法论和双列示例仅作为技术 fixture 或可选样式。

默认选择上下文管理的黑白一组。跨模块反馈较多时，参考评估图的有向闭环。意图识别较紧凑；规划执行适合模块及外围知识较多的章节。重复 PNG/JPG 和拷贝未全部收录。

## 必须继承的视觉特征

文案密度遵守 `text-budget.md`：一框一个知识点，标题加最多两行解释。参考图约束视觉风格，不要求复制其文字数量。

- 竖版整体：标题、副标题、读图说明、横向图例、关系主体、底部总结框。
- 中心是大圆，使用粉紫到蓝青的渐变外环和较深内圆。标题及副文组成一个整体，在圆内水平和垂直居中。
- 第一圈通常约六个较大的圆角模块；外围是与所属模块同色系的浅色小节点。数量由材料决定，不能为了六组补造知识。
- 模块使用蓝、绿、青、橙黄、紫、粉的多色渐变。圆角、阴影和留白以参考 SVG 为准，不改成方形表格卡或胶囊中心。
- 淡同心圆用于组织空间，不表示知识关系；节点之间的实线箭头和虚线才承担关系。
- 强关系标签贴合对应线段的可读位置，用小背景框隔开线与字；不能漂成一个无归属知识节点。
- 除中心与模块关系，还保留有证据的模块间联系；不能只剩树状发散。
- 底部总结框给出本章核心判断及机制之间的联系，保持完整、不截字。
- 白底为纯白或近白，深色字、淡边框、柔和阴影；黑底为暗色背景，浅色标题，外围节点仍为浅色。主题切换保持几何一致。

## 实现边界

参考图约为 1800×2600 或 1800×3000 的逻辑画布；高清导出约 3600×5200 或 3600×6000。规划白底现有 PNG 为 1800×3000，重新高清导出应使用 SVG。不要放大 JPG 冒充高清。

当前 `poster-radial` 固定 3–5 组且最多 21 节点，不能声称直接复现六模块密集参考。超限时扩展径向 JSON 规格与确定性渲染器，或从所附 SVG 提取几何形成可重复生成的模板。仍执行证据校验、文字几何检查、黑白同构和视觉复核。不得把这个视觉目标作为不存在的 profile 参数传给脚本。

历史图片用于视觉参考，其节点和关系不等于已经逐条完成证据审核。新章节必须读取自己的原文，不能搬用示例知识或伪造 evidence_id。参考中的个别重叠、穿框虚线和模糊标签也不应复制。

## 第一性原理与对抗式复核

从学习任务判断：中心是否回答本章解决什么问题，模块是否回答怎么解决，外围是否提供可复习的具体知识，关系能否解释相互作用。

再从反方检查：是否只是换了标题的装饰图；是否把依赖错画成因果；是否为了环绕对称虚构分组；是否用额外连线制造复杂感；是否只检查高清图而忽略课程页面实际显示尺寸。记录具体问题并修正，没有问题时如实记录，不强行为了审查删知识。

手机整图用于总览，细节允许缩放。若要求不缩放直读，应制作另一个精简版，不能把数十个节点缩进手机宽度后声称全部可读。
