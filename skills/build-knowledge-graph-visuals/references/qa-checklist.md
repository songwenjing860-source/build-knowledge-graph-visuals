# 渲染与交付 QA

## 内容必过项

- 中心命题与原文一致。
- 所有节点文案与图谱规格一致。
- 黑底和白底节点、关系、文案完全一致。
- 技术名词、英文大小写、数字和标点准确。
- 强关系都有明确动词标签。
- 推断关系已标注或降级。
- 没有孤立节点、重复节点和装饰边。

## 版式必过项

- 标题、副标题和读图说明没有截断。
- 所有文字位于卡片安全区内。
- 没有文字与文字、文字与箭头、节点与节点重叠。
- 箭头端点落在节点边缘附近，不穿过节点正文。
- 关系标签不覆盖其他关系标签。
- 所有元素位于 viewBox 内。
- 底部总结区没有被截图裁掉。
- 留白能够分隔层级，不靠阴影制造层级。

## 双主题必过项

### 黑底

- 标题和说明文字对比充足。
- 深色标签底与背景可区分。
- 弱关联可见但不抢主线。
- 发光、渐变和阴影没有降低小字清晰度。

### 白底

- 不是简单反色。
- 标题、说明、边标签均为深色文字。
- 浅色圆环和弱关联仍然可见。
- 白色节点通过边框或轻阴影与背景分离。
- 打印或课程白色页面中不显得发灰。

## 移动端必过项

- 明确标注当前是 `mobile` 还是 `poster`。
- `mobile` 在约 390 CSS px 宽下可直接读关键标签。
- `poster` 明确需要点击或缩放，不伪称无需缩放。
- 最长中文标题不溢出。
- 英文长词如 `missing_slots`、`Top1 Accuracy` 不压缩变形。
- 图例和底部总结在缩略显示时仍能识别层级。

## 文件必过项

- SVG 可以直接打开。
- PNG 尺寸等于 SVG 逻辑尺寸乘以渲染倍数。
- JPG 质量不低于 94，且没有明显文字压缩噪声。
- 文件名包含主题：`dark` / `light`。
- 不覆盖用户原始文件，除非用户明确要求。
- 最终文件保存在 workspace，而不是只留在临时目录。

## 失败处理

- 文字越界：扩大节点或缩短副文；不要先缩字号。
- 关系太乱：删除低价值弱关联，重新规划路径。
- 手机太小：降节点数或拆成总图与子图。
- 白底太淡：提高文字、边线和弱关联对比度。
- 黑底太暗：减少背景层次，提高说明文字亮度。
- 双主题漂移：回到共享母版，禁止分别手改内容。

交付前至少查看一次整图和两处小字密集区域的原始像素局部。
